# 信息安全规范

## 账号与权限

所有系统账号必须开启双因素认证，密码长度不少于 12 位，且每 90 天强制更换一次。
离职员工的账号在办理离职当日 18:00 前完成回收，由 IT 运维执行。
权限申请遵循最小权限原则，临时提权有效期最长 24 小时，到期自动回收。

## 数据分级

数据分为公开、内部、机密、绝密四级。
机密及以上数据禁止上传至任何外部网盘、公共大模型服务或个人设备。
对外传输机密数据必须使用公司加密网关，并留存传输审计记录。

## 生产环境操作

生产环境变更必须走发布平台，禁止直接登录生产服务器执行变更。
数据库高危操作（DROP、TRUNCATE、无条件 UPDATE）需两人复核，并在业务低峰期执行。
生产故障按 P0 至 P3 分级，P0 故障需 15 分钟内响应，2 小时内恢复。

## 安全事件上报

发现疑似数据泄露、钓鱼邮件或异常登录，须在 1 小时内上报安全应急邮箱 security@example.com。
隐瞒不报造成损失的，按公司奖惩制度处理。
